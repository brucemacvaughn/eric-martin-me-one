# Eric Martin / Me One — website

The official site for Eric Martin, also known as Me One and MC Eric. Founding member of
Technotronic, co-writer of *Pump Up The Jam, The Album*, owner of Musicated Records.

**Live:** https://www.ericmartinmusic.club

## How it works

Plain HTML, CSS and JavaScript. No framework, no build step, nothing to install. GitHub Pages
serves the `main` branch from the repository root. Commit a change and it is live in about a
minute.

## Pages

| Path | Purpose |
| --- | --- |
| `index.html` | Home — the hook, the two sides of the artist, releases, tour dates, booking |
| `music.html` | Music — releases, Bandcamp player, Spotify, production credits |
| `press.html` | Press / EPK — facts, bios, quotes, stats, downloadable assets |
| `about.html` | About — the full story and timeline |
| `contact.html` | Booking — artist page, booking enquiry form, production form |

## Making changes

**Tour dates** are the most common edit. They live in the `GIGS` array at the top of
`assets/gigs.js`, with instructions in a comment above it. Past dates drop off the site
automatically.

**Menu items** are generated by `assets/main.js` from the `PAGES` array — not written into the
HTML files.

Anything else: read `AGENTS.md` first. It documents the rules that keep the site from breaking,
and it is written for AI coding agents as much as for people.
